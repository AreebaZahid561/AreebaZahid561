## 🚀 Final Year Project

### 🤖 AI-Powered Resume Builder

An **AI-powered ATS-compliant resume builder** designed to help users create optimized resumes without mandatory registration.

**Key Features:**

* 📄 PDF resume import
* 🧠 AI-powered content enhancement
* 📊 ATS score analysis against job descriptions
* ✍️ Grammar and content optimization
* 📥 PDF & DOCX export
* 🎨 Multiple professional resume templates
* 🔒 Local AI processing for privacy
* ⚡ Zero-barrier access — no mandatory login

**Tech Stack:**
`React.js` `Tailwind CSS` `Node.js` `Express.js` `Ollama` `Mistral 7B` `REST APIs` `Docker`
